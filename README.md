# Grade calculator

An interactive Python exercise in `myfirstgradeclac.py`. Enter an integer score from 0 to 100: A starts at 90, B at 80, C at 70, D at 40, and lower scores fail.

## Run

Requires Python 3; no external packages.

```sh
python myfirstgradeclac.py
```

Scores outside the range and non-integer input display `wrong input`.
